# Авито · Найди пару

[Открыть игру](https://imonsergey.github.io/Avitogame/) · [Пульт организатора](https://imonsergey.github.io/Avitogame/?operator=1)

Рабочая игра для одного тачскрина на мероприятии. Базовый холст 1920 × 1080: на других пропорциях окно заполняется расширением сетки, шрифты и иконки масштабируются равномерно. Все изображения и CoFo Avito Display хранятся в репозитории; CDN и внешние запросы во время игры не нужны.

Источник: [актуальная v10 в Figma](https://www.figma.com/design/pLgDa82Ve0CFZAw8b43klW/?node-id=8487-3519). Основные экраны: 8487:3519, 3619, 3902, 3574, 3663, 3742. Ресурсы экспортированы из текущих слоёв, включая пользовательские правки. HTML/CSS и ES-модули без зависимостей.

## Запуск

Node.js 22 или новее:

```sh
npm test
npm run build
npm run dev
```

Открыть `http://localhost:4173`. Для публикации содержимое `dist` отдаётся статическим HTTPS-хостингом. GitHub Actions проверяет и публикует каждый push в `main` на GitHub Pages.

## Механика

- 18 карточек, 9 пар: при каждой попытке случайно выбираются 9 разных предметов из 18, затем перемешиваются их копии. Внутри партии каждая пара имеет свой светлый цвет, который сохраняется при открытии и совпадении.
- Таймер начинается при появлении поля, считает реальное прошедшее время, включая время в фоновой вкладке. Останавливается при выборе последней совпавшей карточки.
- Одновременно можно выбрать только две разные неразгаданные карточки. Ошибочная пара закрывается через 900 мс; правильная остаётся открытой. Быстрые и повторные касания защищены от двойного засчитывания.
- Рестарт во время незавершённой партии требует подтверждения. После подтверждения он обнуляет таймер, отменяет старые анимации и выдаёт новую раскладку. Из результата новая партия начинается сразу. Регистрация сохраняется до выхода на главную.
- После 45 секунд игра продолжается. Подарок отмечается только при результате ≤ 45 000 мс; более медленному игроку предлагается повторить попытку. Так устранено противоречие прототипа, где подарок обещали и при 1:10.
- Рейтинг содержит только реальные завершённые попытки. Один участник определяется по телефону, в рейтинге его лучшая попытка. Сортировка по миллисекундам; при равенстве выше более ранний результат. На экране время показано в формате минут и секунд.
- После 3 минут без взаимодействия экран возвращается на главную, поля регистрации очищаются. Незавершённая попытка в рейтинг не попадает.

## Данные и режим мероприятия

Регистрация и попытки сохраняются транзакционно в IndexedDB **этого браузера на этом устройстве**. Это автономная версия для одного тачскрина, без общей серверной базы. Данные не синхронизируются между браузерами, устройствами и разными адресами сайта. Очистка данных браузера удалит результаты. Не использовать режим инкогнито. Перед мероприятием проверить сохранение и выгрузку на реальном устройстве.

Пульт организатора: добавить `?operator=1` к адресу игры. Он показывает количество записей и позволяет выгрузить CSV с контактами или полный JSON. Пульт не является удалённой админкой: он читает только локальную базу браузера, в котором открыт. Не показывайте его посетителям. Делайте резервную выгрузку в течение мероприятия и перед очисткой устройства.

После первого успешного открытия Service Worker кэширует ресурсы для работы без интернета. При обновлении страницы HTML, CSS и JS запрашиваются из сети с резервной офлайн-копией. Активная партия сама не перезагружается.

## Что менять

- `styles.css` — сетка, цвета и размеры, соответствующие Figma.
- `src/config.js` — условия подарка, название события, адрес стенда, задержки, утверждённые документы.
- `src/app.js` — экраны и управление, экранная клавиатура RU/EN и телефон.
- `src/ranking.js` — карточки участников рейтинга, пустые места и длинные имена.
- `src/icons.js` — единая сетка SVG-иконок кнопок и правил.
- `src/layout.js` — масштаб и размеры полноэкранного холста.
- `src/engine.js` — правила, перемешивание, валидация и сортировка рейтинга.
- `src/storage.js` — регистрация и результаты.
- `assets/products/` — 9 оригинальных изображений; SVG кнопок и карточек — в `assets/`.

## До реального сбора контактов

В макетах отсутствуют юридические документы мероприятия. `termsUrl` и `privacyUrl` оставлены пустыми; по нажатию честно открывается предусмотренное макетом окно «Документ недоступен». **Организатор должен передать утверждённые ссылки до реального сбора персональных данных.** Юридические условия не выдуманы и не заменены общими условиями стороннего сайта.

В тексте подарка оставлено «на стенде М2» из прототипа; адрес меняется в `giftLocation`. Финальный розыгрыш суперприза и проверка победителей происходят у организатора. Локальный рейтинг не имеет серверной защиты от изменения через инструменты разработчика; это версия для контролируемого тачскрина, не для открытого онлайн-турнира.

### Обновление 1.1

В игре есть счётчик 0–9, выход с подтверждением и короткая анимация найденной пары. Незавершённая попытка при выходе не записывается. Таймер продолжает идти, пока открыто подтверждение выхода. Рестарт очищает прогресс и все эффекты. Цвет открытых несовпавших карточек остаётся прежним.

Правила собраны в новую бенто-сетку; на регистрации экранная клавиатура открывается сразу, документы и компактная кнопка «Далее» находятся справа от полей.

Если браузер сохранил старую версию первого релиза, откройте [обновление игры](https://imonsergey.github.io/Avitogame/update.html). Страница активирует новый service worker и возвращает в игру; данные IndexedDB и рейтинг не удаляются. В новых версиях HTML, CSS и JS запрашиваются из сети с резервной офлайн-копией, поэтому обычное обновление страницы получает изменения.

### Обновление 1.2

- У каждой из девяти пар постоянный цвет из палитры Goods Guides B2B / Sellers. При несовпадении и совпадении цвет не меняется; найденная пара получает галочку и короткое свечение. Закрытые карточки одинаковые.
- Регистрация использует всю ширину 16:9: имя и фамилия рядом, телефон ниже, справа большая стрелка 426 × 424. Текст согласия перенесён из предоставленного скриншота; ссылки на документы задаются отдельно в конфигурации.
- Топ-10 показан отдельными карточками в двух колонках без прокрутки: место, имя, время. Пустые места не содержат вымышленных результатов. Длинные имена переносятся на две строки.
- Финал собран в бенто-сетку: медаль, крупное время, условие подарка, три отдельные карточки лидеров и две большие кнопки. Появление сопровождается конфетти; эффекты не перехватывают касания. Учитывается настройка уменьшения движения.
- Добавлены подтверждение рестарта и анимации появления элементов. Модальные окна удерживают клавиатурный фокус, не выделяя случайную кнопку при открытии.

В 1.3.1 возвращён 3D-переворот при открытии и закрытии, с сохранением этого исправления: обе стороны непрозрачны, обратная сторона скрыта, поворачивается только внутренний слой.

Для ручной проверки форматов есть отдельная служебная страница `checks/layout.html`. Она показывает настоящую игру в iframe 1920 × 1080, 1440 × 900 и 2048 × 1029; смена формата не сбрасывает партию. В пользовательский сценарий страница не включена.
